# Archive AR

Arsip proyek dan petunjuk praktikum Augmented Reality menggunakan Unity.

- `DataRafi_new/`: proyek Unity utama.
- `UTS_AR_Template/`: template proyek UTS.
- File PDF di folder utama: petunjuk praktikum.

## Membuka proyek

1. Instal Git LFS, lalu jalankan `git lfs install` sebelum clone repository.
2. Clone repository dan jalankan `git lfs pull` untuk mengambil paket Vuforia dan model FBX.
3. Gunakan Unity Hub untuk membuka salah satu folder proyek dengan Unity **6000.0.34f1**.
4. Masukkan license key Vuforia milik sendiri melalui konfigurasi Vuforia di Unity.

Cache Unity, hasil build, arsip ZIP sumber, dan konfigurasi lokal yang berisi license key tidak disimpan di repository.
